# 과거 원시 RF 재생

`logs/01_final_pass/capture`와 `logs/02_p2_repeat_recovery/capture`의 RFB8·UART·JSONL을 영수증 SHA-256과 대조했다. 최신 분석기로 RFB8 및 A/B 원시 CIR의 CRC를 읽고, 양단 프레임과 DS-TWR를 검산했다. 수치와 거래 목록은 [재생 결과](replay-results.json)에 있다.

| 세션 | P1 최초 확인 | P1 공통축·전력 격자 | P2 공통축·전력 격자 | 기간 |
|---|---:|---:|---:|---|
| 3059936669 | 999/1000, txn 874 재시도 | 1000/1000 | 1000/1000 | 199878.982–200126.490 µs |
| 3340555422 | 999/1000 | 999/1000, txn 870 B 누락 | 1000/1000, txn 366·797 반복 복구 | 199891.683–200126.482 µs |

양쪽 세션에서 앵커·태그가 각각 1,000개 RFB8을 보존했다. 두 번째 세션의 P1 미완결은 그대로 실패로 판정했다. USB FEC/재전송 지표와 별도 저장 성공은 재생 결과의 transport에 기록했다. 물리 지연축은 DS-TWR 및 FP 기반 추정값이다.

USB 조각 CRC 오류는 1차 세션 앵커 2,383건·태그 5,609건, 2차 세션 앵커 2,179건·태그 5,639건이었다. 양쪽 모두 최종 RFB8 CRC 오류와 복원 실패는 0건이었다.

과거 보드 설치 영수증은 태그의 이미지 읽기 해시까지 존재한다. 대표 두 세션의 공통 태그 설치 영수증 SHA-256은 `49869a9af5a849fdf5092515d5f4337769dcfddd8b1fc161ea9f2a725d776066`이다. 앵커 양단의 모든 실험을 단일 이미지 해시까지 연결하지 못했다. 새 펌웨어의 실기 RF 성적은 별도 시험에서 산출한다.
