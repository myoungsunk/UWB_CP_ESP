# Mode 8 통합 비교

기준 원격 SHA는 `44d3e4d93aa5947568b8652a050e5074287449dc`였다. RF 통합 후보 `b73451706b4410e4bc86b3046c55f8e70ba9f7b4`까지의 16개 커밋을 이어받았다. 최종 시험 대상 소스는 `17e496ccb584b4f73cfe75198db7cc08ca33f25b`이다.

- Stage 1–6 `a38338d1cdca`는 동결 증거로 인벤토리에 기록했다. Windows 예약 이름을 포함한 원본은 Git 객체로 직접 해시했다.
- P2 반복 패키지 `ce8f986`의 원시 로그와 이전 기록 형식 분석을 보존했다. 새 세션은 P1/P2 수신 누락 시 새 송수신 시각을 연결한다.
- G8 실제 보드 후보에서 해시가 일치한 저장 경로를 합쳤다. START와 무선 중단 사이에 nonce 회신을 요구하며, 원본 RFB8을 동기화한 뒤 태그 ACK를 보낸다. 유선 런처도 이 태그 저장 경로를 사용한다.
- G10 보드 후보의 파티션 진단·이미지 역할·읽기 검증을 가져왔다. 현 배포에서 이미지 서명 검증이 준비될 때까지 OTA 수신 진입을 닫았다. 기존 원본이 남아 있는 경우에도 OTA를 차단한다.
- G12에는 태그 A/B 장치와 Pi 사이의 USB 마커를 추가했다. 시작 전·측정 중·종료 후의 마커를 수집한다.
- 대체 운영 브랜치 `43193033`의 객체와 커밋을 확인했다. 해당 대체 런타임에 대한 전수 기능 등가성 비교는 남아 있다.
