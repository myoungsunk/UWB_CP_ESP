# 최종 자체 적대적 감사

구현과 별도 단계에서 원시 기록의 결합 조건, 새 회귀시험, 소스와 빌드 해시를 다시 검토했다. 검토자는 구현자와 동일하다.

| 위험 | 판정 | 근거 |
|---|---|---|
| HIGH · P2 보조 POLL이 잘못되면 독립적으로 근거가 확인된 P1도 무효화 | 수정 및 재검증 | P2 최종 프레임·앵커 TX·P1 확인 필드를 검증하면 P1을 계산한다. P2 보조 POLL을 변조하면 P2만 거부하며, P2 최종 TX를 변조하면 둘 다 거부한다. |
| HIGH · G8 태그 ACK 지연과 슬롯 고갈 | 수정 통합 및 호스트 재검증 | 3개·220 ms 한도의 저장 그룹, 파일 동기화 뒤 ACK, 최초 POLL 무단 재실행 방지, 큐 용량 보호. |
| HIGH · G11 장기 운용 중 저장 지연 | 현장 HOLD | 과거 1시간 시험에서 최대 7.679326초까지 저장이 지연됐다. 저장 그룹과 상세 시각 계측을 통합했으며, 최종 이미지의 재시험이 필요하다. |
| HIGH · OTA의 공급자 서명 부재 | 활성화 차단 | USB는 상태만 조회하고 실제 OTA는 공급자 서명 검증 전 단계에서 차단된다. 현장 롤백 결과는 과거 시험 이미지에 귀속한다. |
| MEDIUM · USB 도착 시각을 RF 발생 시각으로 해석 | 검증 기준 추가 | 부팅·세션·라디오·마커를 대조한다. Pi 왕복 범위와 realtime/monotonic 교차 기록을 검사한다. A/B 시각 모델만 제공한다. |
| MEDIUM · Windows 및 스텁 시험이 입력 준비 전에 종료 | 수정 및 재실행 | 역할별 합성 자료를 C++에서 생성하고 pySerial 스텁과 UTF-8 로딩을 교정했다. |

최종 판정은 소스·호스트 및 타깃 빌드 범위에서 수용, 실기 인수 HOLD다. 전체 보안 기능과 모든 장애 주입 조합에 대한 검증은 남아 있다.
